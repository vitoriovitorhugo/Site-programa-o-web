# Site-programa-o-web
Site a respeito das bases da programação web

A plataforma tem como objetivo principal guiar novos desenvolvedores através dos pilares do Front-End.

# O que o site ensina?
Como a Web funciona: O fluxo básico de Cliente/Servidor, requisições HTTP e o papel dos navegadores.
HTML5: A estrutura e a semântica dos elementos de uma página.
CSS3: Estilização, layouts responsivos (Flexbox/Grid) e design visual.
JavaScript: Lógica de programação, manipulação do DOM e interatividade básica.

---

# Tecnologias Utilizadas

Para manter o projeto leve, didático e fiel ao que é ensinado, utilizamos a tríade clássica do desenvolvimento web:

* **HTML5:** Estruturação semântica do conteúdo.
* **CSS3:** Estilização moderna e responsividade (Mobile-First).
* **JavaScript (Vanilla):** Dinamismo e interações da interface.

  Como Contribuir

Contribuições são sempre bem-vindas! Se você deseja melhorar as explicações, corrigir bugs ou adicionar novos módulos:

1. Faça um **Fork** do projeto.
2. Crie uma nova branch com sua modificação: `git checkout -b minha-melhoria`.
3. Salve suas alterações e faça o commit: `git commit -m 'Adicionando módulo de Flexbox'`.
4. Envie para o seu repositório: `git push origin minha-melhoria`.
5. Abra um **Pull Request** detalhando suas alterações.
