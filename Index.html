🧱 HTML5: A Estrutura

O HTML (HyperText Markup Language) é o esqueleto de qualquer página web. Ele utiliza tags para definir onde ficam os textos, imagens, links e botões.

Exemplo de Código:

<button>Clique Aqui</button>
Resultado visual:

🎨 CSS3: O Estilo

O CSS (Cascading Style Sheets) é responsável pela identidade visual. É com ele que adicionamos cores, definimos fontes, alinhamos elementos e criamos layouts responsivos.

Exemplo de Código:

button {
    background-color: #007BFF;
    color: white;
    padding: 10px 20px;
    border: none;
    border-radius: 5px;
}
Resultado visual:

⚡ JavaScript: A Interatividade

O JavaScript é a linguagem de programação que dá vida ao site. Com ele, você pode criar comportamentos dinâmicos, como reagir a cliques, validar formulários e processar dados.

Exemplo de Código:

button.addEventListener('click', () => {
    alert('Olá, Mundo!');
});
